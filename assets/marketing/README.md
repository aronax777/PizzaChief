# Pizza Chief — матеріали для Roblox

Готові зображення, 2026-11-17. Бренд `PIZZA CHIEF` збережено однаково для всіх мов.

| Файл | Розмір | Призначення |
|---|---|---|
| `game-icon-512.png` | 512×512 | Іконка у списку ігор |
| `game-icon-1024.png` | 1024×1024 | Іконка з більшим розміром |
| `thumbnail-hero-1920x1080.png` | 1920×1080 | Основна ілюстрована обкладинка |
| `preview-gameplay-1920x1080.png` | 1920×1080 | Справжній інтерфейс складання Pepperoni |
| `preview-oven-1920x1080.png` | 1920×1080 | Справжній інтерфейс випікання й повороту |
| `preview-gameplay-en-1920x1080.png` | 1920×1080 | Англомовний інтерфейс складання Pepperoni |
| `preview-oven-en-1920x1080.png` | 1920×1080 | Англомовний інтерфейс випікання й повороту |

Рекомендований порядок: ілюстрована обкладинка → складання → випікання. Іконка та hero — рекламні ілюстрації, не скріншоти графіки гри. Чотири gameplay-прев’ю зняті зі справжнього клієнта Studio українською та англійською; UI не домальований. Оригінальні українські PNG та джерела збережено без змін. Англійські знімки показують локалізовану версію з перемикачем мови.

`localization/store-copy.json` і 17 файлів `localization/<locale>.txt` містять локалізовані назви й описи для сторінки гри. Перелік мов і джерела вибору — у [документації локалізації](../../docs/LOCALIZATION.md). Для повторного експорту текстів: `python3 scripts/export_store_copy.py`.

Формати звірені з [Roblox: Icons](https://create.roblox.com/docs/production/publishing/experience-icons) (квадрат, щонайменше 512×512) та [Roblox: Thumbnails](https://create.roblox.com/docs/production/publishing/thumbnails) (16:9, рекомендовано 1920×1080).

Іконка й основна обкладинка створені вбудованим `image_gen.imagegen`. Повні промпти — `prompts.json`; оригінали й неадаптовані скріншоти — `source/`. Точні розміри експортовані через Blender без зміни композиції:

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --threads 4 --python scripts/export_marketing.py
```

Для експорту лише нових англомовних прев’ю без перезапису українських додайте `-- --only-english`. Manifest зберігає записи інших зображень.

`manifest.json` фіксує розміри, походження та вид кожного зображення. Усі PNG відкриті й перевірені. Файли готові для Creator Dashboard; зміни іконки/прев’ю на Roblox і публікація оновленої гри в цьому чаті не виконувалися.
