# Pizza Chief — Second Serving

Roblox-прототип про майстерність піцайоло: 20 рецептів, 28 інгредієнтів, керування жаром, короткі зміни, колекція зірок і чесні змагання. Український інтерфейс та процедурна 3D-піцерія без платних зовнішніх ассетів.

## Запуск

Відкрийте `PizzaChief.rbxlx` у Roblox Studio → **Play** → **ПОЧАТИ ЗМІНУ**. На екрані замовлення видно рецепт, умову контракту, ціль і таймер.

1. Кнопками **+ / −** додайте потрібні порції. Інгредієнти поточного замовлення стоять першими в коморі.
2. **У ПІЧ** → керуйте верхнім бігунком, кнопками або **A / D**. Тримайте температурну стрілку в зеленій зоні.
3. **ПОДАТИ** → оцінка шефа, XP, зірки, особистий рекорд і наступне замовлення.

Клавіатурне й сенсорне керування орієнтовані на комп’ютер та планшет у горизонтальному режимі. Рух персонажа вимкнений: прототип керується через кухонний інтерфейс.

## Чому грати ще раз

- **Зміна шефа:** три різні рецепти; класика 90 с → неслухняна піч 80 с → годинапік 65 с. Рекорд — сума трьох оцінок із 300. Невдале замовлення не завершує всю зміну.
- **Ранги:** 8 титулів від учня до легенди. XP поступово розширює кар’єрний каталог із 6 до 20 рецептів. У вільному тренуванні всі рецепти відкриті відразу.
- **Паспорт піц:** до 3 зірок за кожен рецепт,60 загалом; зберігається найкращий результат, повтори не дублюють зірки.
- **Серія:** результат 80+ збільшує комбо до×5. Комбо продовжується між режимами й змінами в межах сесії; нижчий результат його скидає. Бонус впливає на XP, а не на чесність Battle.
- **Виклик дня:** той самий рецепт і модифікатор для всіх за UTC-добу;85+ дає 60 додаткових XP один раз за день. Повторні спроби покращують окремий рекорд дня. Пропуск дня нічого не забирає.
- **Pizza Battle:** 2–6 гравців, 10 с на старт, 90 с на однаковий рецепт. Видимий переможець, таблиця результатів і кнопка реваншу.
- **Картка результату:** готовий екран для скріншота та добровільна кнопка запрошення друзів у Roblox.

Значки відмічають конкретні досягнення: перша подача, три зірки, п’ять піц поспіль, завершена зміна та перемога над іншими кухарями. Подробиці й дизайнерські гіпотези — у `docs/GAME_DESIGN.md`.

## Оцінювання

Якість =65% відповідності рецепту +35% випікання. Підсумок =80% якості +20% швидкості. Рецепт штрафує пропуски, зайві інгредієнти й неправильні порції. Швидкість має власний орієнтир для кожного рецепта: тривалість випікання +6 секунд +0,5 секунди за порцію; додатковий час поступово зменшує оцінку.

Для 3 ★ потрібні рецепт≥95%, піч≥90% і підсумок≥90. Клієнт не призначає собі оцінки, XP, рекорди чи нагороди. Усі таймери й нагороди перевіряє сервер.

## Збереження та друзі

У Studio прогрес існує лише до зупинки Play; інтерфейс це явно показує. На опублікованому Roblox-сервері `ProfileStore` використовує DataStore для XP, зірок, рекордів і перемог; захоплення сесії захищає від одночасного перезапису. Якщо профіль не завантажився, сервер не перезаписує його порожнім.

Запрошення відкриває стандартний вибір друзів Roblox лише після натискання гравцем. У неопублікованій грі показується пояснення. Для локального multiplayer-тесту використовуйте **Server & Clients → 2 clients** і приєднайте обох до кімнати. Кімната працює всередині одного Roblox-сервера; міжсерверного matchmaking тут немає.

Опубліковано закриту тестову версію [Pizza Chief - Private Test](https://www.roblox.com/games/100802426129317). Доступ ранніх тестувальників налаштовано для трьох друзів; загального публічного доступу немає. Стан публікації, перевірок і обмежень зафіксовано в `docs/PRIVATE_TEST.md`.

## Джерела й збірка

- `src/shared/Recipes.luau` — каталог і кулінарне оцінювання.
- `src/shared/GameRules.luau` — контракти, ранги, зірки, комбо й значки.
- `src/server/GameServer.server.luau` — авторитетна логіка гри й кімнат.
- `src/server/ProfileStore.luau` — збереження прогресу.
- `src/client/PizzaClient.client.luau` — інтерфейс, прев’ю піци, керування й соціальні дії.
- `src/studio/BuildWorld.luau` — процедурна піцерія.
- `screenshots/replay/` — скріншоти версії Second Serving.

```sh
python3 scripts/build_place.py --scene artifacts/scene.json
python3 scripts/build_place.py --scene artifacts/scene.json --output PizzaChief.rbxlx
```

Збірка використовує Python standard library й перевіряє точні байти всіх вбудованих скриптів. Без `--scene` створюється легкий пакет, що будує кухню після Play.

## Перевірки

Перевірено локальний multiplayer з двома справжніми клієнтами Studio: повний матч, спільні таймери, оцінки, переможець, реванш зі зміною переможця та 90-секундний тайм-аут без переможця. Сценарій і докази — у `docs/MULTIPLAYER_TEST.md`, `tests/multiplayer-session.json` та `screenshots/multiplayer/`. Готування автоматизувалося через реальні клієнтські remotes; вступ і реванш — натисканнями UI.

`tests/replay-validation.json` містить 110 пройдених перевірок і хеші джерел:47 серверних, 48 правил/рецептів, 15 збереження. Harness виконує справжній Luau-код із локальними замінами гравців, годинника та DataStore; не пише в хмару. Це не замінює мережевий тест справжніх клієнтів або реальний playtest із гравцями.

Генератори: `tests/build_room_harness.py`, `tests/build_progression_harness.py`, `tests/build_profile_harness.py`. Згенеровані Luau-файли запускаються через Studio MCP у правильному PizzaChief-вікні. Рецепти — ігрові спрощення; джерела й формули описані в `docs/RECIPES.md`.

Після виправлення гонок збереження виконано ще 74 ізольовані перевірки актуальних серверних джерел: завантаження профілю, швидкий повторний вхід, фінальне збереження під час autosave і завершення сервера. Докази та хеші — `tests/persistence-race-validation.json`; додатковий генератор — `tests/build_shutdown_harness.py`. Це перевірки з підставним DataStore, без запису в хмару.
