# Fresh from the Oven — 2026-11-17

## Готування

- Комора показує великі картки зі спрайтами й потрібною кількістю порцій. Спочатку відкриті тільки інгредієнти замовлення. «Усі 28» відкриває весь каталог, по вісім карток на сторінку.
- Натискання на зображення або `+` додає одну порцію; `−` прибирає. Клавіші `1–7` відповідають номерам потрібних інгредієнтів; `Shift` + номер прибирає порцію.
- Чекліст показує фактичні / потрібні порції; правильні картки зелені, зайві — червонуваті. Інгредієнт летить до піци лише після підтвердження сервером.
- Підказка Луки називає наступний відсутній інгредієнт. Після точного складання пропонує випікання. У піч можна відправити й неточний рецепт — свобода експериментів збережена.
- `Space`: у піч → повернути піцу → подати. `A / D`, кнопки або бігунок керують жаром. Клієнт не обробляє ці клавіші поверх відкритої книги рецептів або текстового поля.
- Під час випікання видно якість, температурну зону та підказку, в який бік змінити жар.

## Поворот піци

Вікно повороту — 36–64% тривалості випікання; ідеальна зона — 44,5–55,5%. Золотиста частина шкали позначає ідеальний момент. Поворот у широкому вікні дає +3 до оцінки печі, в ідеальному — +6. Оцінка печі обмежена 100. Поворот доступний один раз; повторні remotes не накопичують бонус. Час і бонус визначає сервер, аргументи клієнта не використовуються.

Пропуск не штрафує: стара оцінка за керування температурою збережена. Бонус застосовується до випікання перед незмінною формулою загального результату. У Battle правила однакові для всіх. На екрані результату видно бонус повороту.

## Авторські спрайти

`assets/ingredients/` містить 28 PNG 256×256 із прозорістю, атлас 1792×1024 (7×4), `manifest.json` і редагований `ingredients.blend`. Усі моделі й матеріали створені процедурно у Blender; сторонніх ассетів немає.

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --threads 6 --python scripts/render_ingredients.py
```

Скрипт також створює `src/shared/IngredientPixels.luau`: компактні 64px прев’ю оригінальних рендерів. `IngredientArt` кешує EditableImage і використовує ті самі пікселі як GUI-смуги, якщо динамічні зображення недоступні. Тому локальна збірка показує весь набір без HTTP, asset ID, зовнішніх файлів або дозволів на завантаження. Каталог обмежений вісьмома картками на сторінку, щоб обмежити кількість GUI-елементів запасного renderer.

`IngredientArt.Atlas` дозволяє підключити схвалений Roblox-атлас у майбутньому. У цій збірці він порожній; використовується вбудована графіка. Завантаження ассетів і публікація оновленої гри не виконані. MCP API відхилив `asset:read` / `asset:write`; після дозволу користувача інструмент керування UI повертав `noWindowsAvailable` на натискання в налаштуваннях Studio. Це не заважає вбудованим спрайтам працювати.

## Перевірка

- 157 ізольованих перевірок фактичного Luau-коду: 84 серверні/готування, 48 правил, 21 профілю, 4 завершення сервера. Жодних записів у хмарний DataStore.
- 11 перевірок справжнього клієнта Studio через реальні remotes: зайва начинка, корекція, чекліст, випікання, ранній/ідеальний поворот, подача та результат. Контрольований прогін: 100 балів, 3 зірки, +6 до печі.
- Після розблокування Mac перевірено справжні mouse/keyboard input: повторна спроба, клавіші інгредієнтів, `Shift` для видалення, `Space` для випікання, `D` для збільшення жару.
- Окремо перевіряється повнота всіх 28 вбудованих зображень і запасний GUI-renderer. Звіт: `tests/fresh-validation.json`.
- Скріншоти підготовки й випікання: `screenshots/fresh/`.

Це автоматизований playtest, не оцінка захопливості реальними гравцями. Повний мережевий матч із двома клієнтами в цьому оновленні не повторювався; серверний harness перевіряє кімнати та нарахування результатів.
